# azphalt-brush-watercolor

Brush packages for the "watercolor" collection, each in its own `brushes/<slug>/` folder (manifest.json + LICENSE + assets/tip.png):

- `brushes/watercolor-wet-on-wet/` — **Wet-on-Wet** — A soft, irregular bloom that mimics pigment bleeding into wet paper.
- `brushes/watercolor-wash-flat/` — **Wash Flat** — A broad, soft-edged wash brush with uneven, blotchy opacity. Rotate with angle.
- `brushes/watercolor-salt-texture/` — **Salt Texture** — A granular wash with salt-crystal speckling, pulling pigment into starbursts.
- `brushes/watercolor-dry-edge-bleed/` — **Dry-Edge Bleed** — A wash with a firmer core fading into wispy, irregular bleeding edges.

`node build.js` packs every subfolder into its own `.azp`.
